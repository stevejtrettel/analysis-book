# Opener Purpose — unnumbered notation chapter

Goals-first workflow; see `purpose-ch1.md` header for the content rule.

## Goals

- Owes the course: notation and conventions only — logic, quantifiers,
  sets, functions (injective/surjective/bijective as vocabulary),
  induction. Readable in one sitting.
- Exit state: the reader can parse every formula in Ch 1.
- Non-goals: no cardinality theory (Ch 2 twist); no fields/order
  (Ch 1's world); no theorems that carry plot.

## Story

- Deliberately none — that is its design. The story budget is spent on
  the numbered chapters; this page exists so the book's first numbered
  page can be mathematics.
