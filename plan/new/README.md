# New outline

Fresh outlining for the rebuild starts here. Source layers and per-chapter
authority verdicts: `../MAP.md`.

Goals-first workflow: each Part I chapter gets a `purpose-chN.md`
(Goals / Story / Ledger / Status), adjudicated *before* its section
list is written. Content earns its place only by serving a named goal
or the story, or by being a named debt. Chapter shapes: `part1-chapters.md`.

`sources/` holds research-verification docs: sourcing for historical
and etymological claims, with ⚠ VERIFY flags for anything needing a
library check before it is quoted in print.

decisions for that chapter. To see everything open, read the Status
sections of `purpose-ch0.md` through `purpose-ch13.md` — the full
set now exists (Ch 8–13 are Continuity, Differentiation, Integration,
The Calculus, Elementary Functions, Pi under the seven-chapter
