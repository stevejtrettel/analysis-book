\section{Sets and Functions}\label{sec-foundations-sets-functions}

\textbf{Narrative}

\begin{itemize}
\tightlist
\item
  Before discussing numbers, we need the language of sets and functions
\item
  This is vocabulary and notation---mostly review from intro to proofs
\item
  Functions are assignments, not formulas: ``1 if rational, 0 if
  irrational'' is a valid function
\item
  Injective/surjective/bijective capture ways functions ``match up''
  sets
\item
  Inverses exist precisely when bijective
\item
  Foreshadowing: Cantor's argument (no surjection
  \(A \to \mathcal{P}(A)\)) connects to uncountability later
\end{itemize}

\textbf{Definitions}

\begin{itemize}
\tightlist
\item
  Set, element, membership (\(\in\), \(\notin\))
\item
  Set-builder notation: \(\{x : P(x)\}\)
\item
  Standard sets: \(\NN\), \(\ZZ\), \(\QQ\) (convention:
  \(0 \notin \NN\))
\item
  Subset: \(A \subseteq B\)
\item
  Set equality: \(A = B\) iff \(A \subseteq B\) and \(B \subseteq A\)
\item
  Union, intersection, difference
\item
  Cartesian product: \(A \times B\)
\item
  Function: \(f: A \to B\), domain, codomain, range
\item
  Injective: \(f(x_1) = f(x_2) \Rightarrow x_1 = x_2\)
\item
  Surjective: range equals codomain
\item
  Bijective: injective and surjective
\item
  Composition: \((g \circ f)(x) = g(f(x))\)
\item
  Inverse function: \(f^{-1}\)
\end{itemize}

\textbf{Results}

\begin{itemize}
\tightlist
\item
  \(f\) has an inverse iff \(f\) is bijective
\end{itemize}

\textbf{Exercises}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  De Morgan: \((A \cap B)^c = A^c \cup B^c\)
\item
  \(A \setminus (B \cup C) = (A \setminus B) \cap (A \setminus C)\)
\item
  Composition is associative
\item
  \(f\) bijective \(\Rightarrow\) \(f^{-1}\) bijective and
  \((f^{-1})^{-1} = f\)
\item
  \(f, g\) bijective \(\Rightarrow\)
  \((g \circ f)^{-1} = f^{-1} \circ g^{-1}\)
\item
  \(f\) bijective iff left and right inverse exists
\item
  \(g \circ f\) injective/surjective: what about \(f\) and \(g\)?
\item
  ★ No surjection \(A \to \mathcal{P}(A)\) (Cantor)
\end{enumerate}

\section{Ordered Fields}\label{sec-foundations-ordered-fields}

\textbf{Narrative}

\begin{itemize}
\tightlist
\item
  We axiomatize arithmetic abstractly: field axioms capture \(+\) and
  \(\times\)
\item
  \(\QQ\) is a field; \(\ZZ\) is not (no multiplicative inverses)
\item
  Consequences flow from axioms: uniqueness of inverses,
  \(0 \cdot a = 0\), \((-1)(-1) = 1\)
\item
  Add order via positivity axioms: trichotomy, closure under \(+\) and
  \(\times\)
\item
  Squares are nonnegative; \(1 > 0\); multiplying by negatives reverses
  inequalities
\item
  Absolute value measures distance: \(|a - b|\) is distance between
  \(a\) and \(b\)
\item
  Triangle inequality: fundamental tool for estimation
\item
  Intervals: notation for ``chunks'' of the number line
\item
  Warning: \(\infty\) and \(-\infty\) are notation, not numbers
\item
  Bernoulli's inequality: \((1+x)^n \geq 1 + nx\)---used later for
  bounding \(e\)
\item
  Roots notation introduced, but existence requires completeness (coming
  in 1.5)
\end{itemize}

\textbf{Definitions}

\begin{itemize}
\tightlist
\item
  Field: \(+\), \(\times\) with commutativity, associativity,
  identities, inverses, distributivity
\item
  Ordered field: field with positive elements \(P\) satisfying closure
  and trichotomy
\item
  Inequality: \(a < b\) means \(b - a \in P\)
\item
  Absolute value: \(|a| = a\) if \(a \geq 0\), \(-a\) if \(a < 0\)
\item
  Intervals: \((a,b)\), \([a,b]\), \([a,b)\), \((a,b]\)
\item
  Rays: \([a, \infty)\), \((a, \infty)\), \((-\infty, a]\),
  \((-\infty, a)\)
\item
  Roots notation: \(\sqrt[n]{a}\), rational powers \(a^{p/q}\)
\end{itemize}

\textbf{Results}

\begin{itemize}
\tightlist
\item
  Uniqueness of additive and multiplicative inverses
\item
  \(0 \cdot a = 0\)
\item
  \((-1) \cdot a = -a\)
\item
  \(a^2 \geq 0\), with equality iff \(a = 0\)
\item
  \(1 > 0\)
\item
  Transitivity of \(<\)
\item
  \(a < b \Rightarrow a + c < b + c\)
\item
  \(a < b\) and \(c > 0 \Rightarrow ac < bc\); \(c < 0\) reverses
\item
  Triangle inequality: \(|a + b| \leq |a| + |b|\)
\item
  Reverse triangle inequality: \(||a| - |b|| \leq |a - b|\)
\item
  Bernoulli: \((1 + x)^n \geq 1 + nx\) for \(x > -1\)
\end{itemize}

\textbf{Remarks}

\begin{itemize}
\tightlist
\item
  \((a - r, a + r) = \{x : |x - a| < r\}\)
\item
  \(\infty\), \(-\infty\) are notation only, not field elements
\end{itemize}

\textbf{Exercises}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Zero-product property: \(ab = 0 \Rightarrow a = 0\) or \(b = 0\)
\item
  Fraction addition formula
\item
  Finite geometric sum
\item
  \(\CC\) cannot be ordered
\item
  \(a < b \Rightarrow a < \frac{a+b}{2} < b\)
\item
  \((a, b) \neq \varnothing\) when \(a < b\)
\item
  ★ Binary arithmetic
\item
  ★ Uniqueness of base-\(b\) representations
\end{enumerate}

\section{Incompleteness}\label{sec-foundations-incompleteness}

\textbf{Narrative}

\begin{itemize}
\tightlist
\item
  Greeks discover \(\sqrt{2}\) irrational: geometry demands a number
  \(\QQ\) doesn't have
\item
  First patch attempt: adjoin \(\sqrt{2}\) to get
  \(\QQ(\sqrt{2})\)---but now \(\sqrt{3}\) is missing
\item
  Adjoin more roots? Still miss \(\sqrt{5}\), \(\sqrt{7}\),
  \(\sqrt{2 + \sqrt{3}}\), \ldots{}
\item
  Go to infinity: constructible numbers (all nested square roots)---but
  miss \(\sqrt[3]{2}\)
\item
  Go to infinity again: algebraic numbers \(\AA\) (all polynomial
  roots)---but miss \(\pi\)
\item
  Hopelessness: every patch leaves holes, can't construct our way to
  completeness
\item
  The real crisis: gaps aren't just aesthetic---they break calculus
\item
  IVT, EVT, MVT all fail in \(\QQ\); derivatives lose connection to
  function behavior
\item
  Newton's method and bisection produce sequences with no limit in
  \(\QQ\)
\item
  New strategy needed: define \(\RR\) by properties (completeness), not
  construction
\end{itemize}

\textbf{Definitions}

\begin{itemize}
\tightlist
\item
  \(\QQ(\sqrt{2}) = \{a + b\sqrt{2} : a, b \in \QQ\}\)
\item
  Constructible numbers: iterated square roots from \(\QQ\)
\item
  Algebraic numbers \(\AA\): roots of polynomials with integer
  coefficients
\item
  Transcendental: not algebraic
\end{itemize}

\textbf{Results}

\begin{itemize}
\tightlist
\item
  \(\sqrt{2}\) is irrational
\item
  \(\QQ(\sqrt{2})\) is a field, but \(\sqrt{3} \notin \QQ(\sqrt{2})\)
\item
  Doubling the cube impossible: \(\sqrt[3]{2}\) not constructible
\item
  \(\pi\) is transcendental (Lindemann 1882)
\item
  Algebraic closure: \(\AA\) closed under polynomial roots
\end{itemize}

\textbf{Examples}

\begin{itemize}
\tightlist
\item
  IVT fails in \(\QQ\): \(f(x) = x^2 - 2\) on \([1,2] \cap \QQ\)
\item
  EVT fails in \(\QQ\): \(f(x) = 1/(x^2 - 2)\) unbounded on
  \([1,2] \cap \QQ\)
\item
  MVT fails in \(\QQ\) (depends on EVT)
\end{itemize}

\textbf{Remarks}

\begin{itemize}
\tightlist
\item
  Constructibles satisfy polynomials of degree \(2^n\); \(\sqrt[3]{2}\)
  satisfies degree 3
\end{itemize}

\textbf{Exercises}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \(\sqrt{6}\) irrational
\item
  \(\sqrt{p}\) irrational for \(p\) prime
\item
  Verify \(\QQ(\sqrt{2})\) is a field
\item
  ★ \(\sqrt{3} \notin \QQ(\sqrt{2})\)
\item
  \(\sqrt{2} + \sqrt{3}\) irrational
\item
  ★ \(\QQ(\sqrt{2}, \sqrt{3})\) is a field
\item
  Bisection algorithm: \(a_n^2 < 2 < b_n^2\) and \(b_n - a_n = 2^{1-n}\)
\item
  ★★ Liouville numbers: construct transcendentals before Lindemann
\end{enumerate}

\section{Completeness}\label{sec-foundations-completeness}

\textbf{Narrative}

\begin{itemize}
\tightlist
\item
  Recall bisection for \(\sqrt{2}\): nested intervals
  \([1,2] \supset [1.4, 1.5] \supset [1.41, 1.42] \supset \cdots\)
\item
  In \(\QQ\), intersection is empty---the target doesn't exist
\item
  Left endpoints increase, right endpoints decrease---want ``max'' and
  ``min'' but they don't exist
\item
  Need a way to name the target these endpoints approach
\item
  Supremum: the least upper bound---may or may not be in the set
\item
  Key example: \(\{x \in \QQ : x^2 < 2\}\) has no supremum in
  \(\QQ\)---this is how holes manifest
\item
  Completeness axiom: every nonempty set bounded above has a supremum
\item
  \(\varepsilon\)-characterization: the workhorse for supremum
  arguments---``get within \(\varepsilon\) of the sup''
\item
  Working with sup: translation, scaling, subsets, unions
\item
  Nested Interval Property: completeness delivers what we
  wanted---nested closed intervals have nonempty intersection
\item
  This is what ancient mathematicians assumed when approximating \(\pi\)
  or \(\sqrt{2}\)
\item
  Next section: assume completeness as an axiom, define \(\RR\), explore
  what this buys us
\end{itemize}

\textbf{Definitions}

\begin{itemize}
\tightlist
\item
  Bounds: upper bound, lower bound, bounded above/below/bounded
\item
  Supremum: least upper bound
\item
  Infimum: greatest lower bound
\item
  Complete ordered field: every nonempty set bounded above has a
  supremum
\item
  Nested intervals: \(I_{n+1} \subseteq I_n\) for all \(n\)
\end{itemize}

\textbf{Results}

\begin{itemize}
\tightlist
\item
  Uniqueness of sup and inf
\item
  \(\QQ\) is not complete
\item
  In a complete field, infima also exist
\item
  \(\varepsilon\)-characterization of sup: can get within
  \(\varepsilon\) of sup
\item
  \(\varepsilon\)-characterization of inf
\item
  \(\sup(A + c) = \sup A + c\)
\item
  \(\sup(cA) = c \cdot \sup A\) for \(c > 0\)
\item
  \(A \subseteq B \Rightarrow \sup A \leq \sup B\)
\item
  \(\sup(A \cup B) = \max\{\sup A, \sup B\}\)
\item
  Nested Interval Property: \(\bigcap [a_n, b_n] \neq \varnothing\) in
  complete fields
\end{itemize}

\textbf{Examples}

\begin{itemize}
\tightlist
\item
  \(\sup\{1 - 1/n\} = 1 \notin S\)
\item
  \(\sup[0,1] = 1 \in S\)
\item
  \((0,1)\): sup and inf not in set
\item
  \(\{x \in \QQ : x^2 < 2\}\) has no sup in \(\QQ\)
\end{itemize}

\textbf{Remarks}

\begin{itemize}
\tightlist
\item
  Lengths \(\to 0\) implies intersection is single point
\item
  Nested intervals fails in \(\QQ\)
\end{itemize}

\textbf{Exercises}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Uniqueness of inf
\item
  \(\varepsilon\)-characterization of inf
\item
  \(A \subseteq B \Rightarrow \sup A \leq \sup B\)
\item
  \(\sup(cA) = c \cdot \sup A\)
\item
  Sup/inf of unions
\item
  Find sup/inf: \([1,3]\), \([1,3)\), \(\{x \in \QQ : x^2 < 1\}\), etc.
\item
  Find sup/inf: \(\{(-1)^n/n\}\), \(\{\beta^n\}\), \(\{\gamma^n\}\)
\item
  \(\sup A < \sup B \Rightarrow\) some \(b \in B\) is upper bound for
  \(A\)
\item
  Open intervals with \(\sup A = \inf B\): can one point make an
  interval?
\item
  Nested open intervals with empty intersection
\item
  ★ Lengths \(\to 0\) implies single point
\item
  ★ Sup-completeness \(\Leftrightarrow\) inf-completeness
\end{enumerate}

\section{The Real Numbers}\label{sec-foundations-reals}

\textbf{Narrative}

\begin{itemize}
\tightlist
\item
  The bold move: we \emph{declare} \(\RR\) to be a complete ordered
  field
\item
  Axiomatic method: specify properties, not construction---we say what
  reals \emph{do}, not what they \emph{are}
\item
  Existence and uniqueness theorem: these axioms describe exactly one
  thing (up to isomorphism)
\item
  First check: no monsters---no infinite or infinitesimal numbers
\item
  \(\NN\) unbounded: if bounded, \(\sup \NN\) would exist, but then
  \((\sup \NN) - 1\) not an upper bound, contradiction
\item
  Archimedean property: ``you can empty the ocean with a
  teaspoon''---enough copies of any positive number exceed any bound
\item
  Complete \(\Rightarrow\) Archimedean
\item
  Density: \(\QQ\) and irrationals both dense in \(\RR\)---we filled
  gaps, didn't add alien regions
\item
  The payoff: \(\sqrt{2}\) exists! Use completeness:
  \(\sup\{x : x^2 < 2\}\) works
\item
  With roots, we build rational exponents, then real exponents, then
  logarithms
\item
  Completeness lets us build all the functions we need---these are the
  ``new treasures'' of \(\RR\)
\item
  Surprise: \(\RR\) is uncountable (nested intervals proof)

\textbf{Telescoping Series}

\begin{itemize}
\tightlist
\item

\item

\item

\textbf{Telescoping Products}

\begin{itemize}
\tightlist
\item

\item
  If aₖ = tₖ/tₖ₋₁, then Pₙ = Πₖ aₖ = tₙ/t₀
\item

\item

\end{itemize}

\textbf{The Question}

\begin{itemize}
\tightlist
\item

\end{itemize}

\section{Continuity on Closed

\textbf{The Intermediate Value Theorem}

\begin{itemize}
\tightlist
\item
  \textbf{Theorem (IVT)}: If f continuous on {[}a,b{]} and y between
  f(a) and f(b), then f(c) = y for some c
\item
  Proof via completeness: c = sup\{x : f(x) \textless{} y\}
\item
  \textbf{Corollary}: Continuous image of interval is interval
\item
  \textbf{Applications}:

  \begin{itemize}
  \tightlist
  \item
    nth roots exist (f(x) = xⁿ)
  \item
    Fixed point theorem: f: {[}a,b{]} → {[}a,b{]} continuous ⟹ f(c) = c
    for some c
  \item
    Every odd-degree polynomial has a real root
  \end{itemize}
\end{itemize}

\textbf{Boundedness and the Extreme Value Theorem}

\begin{itemize}
\tightlist
\item
  \textbf{Theorem}: Continuous on {[}a,b{]} ⟹ bounded

  \begin{itemize}
  \tightlist
  \item
    Proof via Bolzano-Weierstrass
  \end{itemize}
\item
  \textbf{Theorem (EVT)}: Continuous on {[}a,b{]} ⟹ attains maximum and
  minimum

  \begin{itemize}
  \tightlist
  \item
    Proof via BW: xₙ with f(xₙ) → sup f; extract convergent subsequence
  \end{itemize}
\end{itemize}

\textbf{Monotone Functions and Inverses}

\begin{itemize}
\tightlist
\item
  \textbf{Definition}: increasing, decreasing, strictly monotone
\item
  \textbf{Theorem}: Monotone on (a,b) ⟹ one-sided limits exist at every
  point

  \begin{itemize}
  \tightlist
  \item
    Proof via sup/inf
  \end{itemize}
\item

\item

\item

\section{Uniform Continuity}\label{uniform-continuity}

\textbf{The Problem}

\begin{itemize}
\tightlist
\item
  In ordinary continuity, δ depends on ε \emph{and} the point a
\item
  Can one δ work for all points simultaneously?
\end{itemize}

\textbf{Definition}

\begin{itemize}
\tightlist
\item
  f uniformly continuous on S if ∀ε \textgreater{} 0 ∃δ \textgreater{}
  0: x, y ∈ S and \textbar x − y\textbar{} \textless{} δ ⟹ \textbar f(x)
  − f(y)\textbar{} \textless{} ε
\end{itemize}

\textbf{Non-examples}

\begin{itemize}
\tightlist
\item
  f(x) = 1/x on (0,1): near 0, need smaller and smaller δ
\item
  f(x) = x² on ℝ: as x → ∞, function changes faster and faster
\end{itemize}

\textbf{Results}

\begin{itemize}
\tightlist
\item
  \textbf{Theorem}: Uniformly continuous ⟹ continuous (trivial)
\item
  \textbf{Theorem}: Continuous on {[}a,b{]} ⟹ uniformly continuous on
  {[}a,b{]}

  \begin{itemize}
  \tightlist
  \item
    Proof via BW: if not, get sequences xₙ, yₙ with \textbar xₙ −
    yₙ\textbar{} → 0 but \textbar f(xₙ) − f(yₙ)\textbar{} ≥ ε; extract
    convergent subsequence, get contradiction
  \end{itemize}
\item
  \textbf{Extension Theorem}: Uniformly continuous on (a,b) ⟹ extends to
  continuous function on {[}a,b{]}

  \begin{itemize}
  \tightlist
  \item
    Proof: show lim\_\{x→a⁺\} f(x) exists via Cauchy criterion
  \end{itemize}
\item
  \textbf{Corollary}: Uniformly continuous on bounded set ⟹ bounded
\end{itemize}

\chapter{Differentiation}\label{differentiation}

\section{Differentiation Rules}\label{differentiation-rules}

\begin{itemize}
\tightlist
\item
  f differentiable at a if lim\_\{h→0\} (f(a+h) - f(a))/h exists
\item
  Alternative form: lim\_\{x→a\} (f(x) - f(a))/(x - a)
\item
  Notation: f'(a), df/dx, Df(a)
\end{itemize}

\textbf{Differentiability Implies Continuity}

\begin{itemize}
\tightlist
\item
  Theorem: f differentiable at a ⟹ f continuous at a
\item
  Warning: converse false! \textbar x\textbar{} at 0
\end{itemize}

\textbf{Basic Rules}

\begin{itemize}
\tightlist
\item
  Linearity: (f + g)' = f' + g', (cf)' = cf'
\item
  Product rule: (fg)' = f'g + fg'
\item
  Quotient rule: (f/g)' = (f'g - fg')/g²
\item
  Power rule: (xⁿ)' = nxⁿ⁻¹
\end{itemize}

\textbf{Chain Rule}

\begin{itemize}
\tightlist
\item
  Theorem: (f ∘ g)`(a) = f'(g(a)) · g'(a)
\item
  Proof via auxiliary function φ (handles g(a+h) = g(a) case)
\item
  Leibniz notation: dy/dx = (dy/du)(du/dx)
\end{itemize}

\textbf{Inverse Function Derivative}

\begin{itemize}
\tightlist
\item
  Theorem: (f⁻¹)`(f(a)) = 1/f'(a) when f'(a) ≠ 0
\item
  Leibniz notation: dx/dy = 1/(dy/dx)
\item
  Example: (√x)' = 1/(2√x)
\end{itemize}

\section{The Mean Value Theorem}\label{the-mean-value-theorem}

\textbf{Fermat's Theorem}

\begin{itemize}
\tightlist
\item
  Theorem: f has local extremum at c and f differentiable at c ⟹ f'(c) =
  0
\item
  Proof: one-sided difference quotients have opposite signs
\end{itemize}

\textbf{Rolle's Theorem}

\begin{itemize}
\tightlist
\item
  Theorem: f continuous on {[}a,b{]}, differentiable on (a,b), f(a) =
  f(b) ⟹ f'(c) = 0 for some c ∈ (a,b)
\item
  Proof via EVT + Fermat
\end{itemize}

\textbf{The Mean Value Theorem}

\begin{itemize}
\tightlist
\item
  Theorem: f continuous on {[}a,b{]}, differentiable on (a,b) ⟹ f(b) -
  f(a) = f'(c)(b-a) for some c
\item
  Proof: apply Rolle to g(x) = f(x) - \href{x-a}{(f(b)-f(a))/(b-a)}
\item
  Geometric interpretation: some tangent parallel to secant
\end{itemize}

\textbf{Cauchy's Mean Value Theorem}

\begin{itemize}
\tightlist
\item
  Theorem: (f(b) - f(a))g'(c) = (g(b) - g(a))f'(c) for some c
\item
  Proof: Rolle applied to appropriate combination
\end{itemize}

\textbf{Consequences: f' Controls f}

\begin{itemize}
\tightlist
\item
  Theorem: f' = 0 on interval ⟹ f constant
\item
  Theorem: f' \textgreater{} 0 on interval ⟹ f strictly increasing
\item
  Corollary: f' ≥ 0 ⟺ f increasing; f' ≤ 0 ⟺ f decreasing
\item
  Remark: first/second derivative tests for extrema in exercises
\end{itemize}

\textbf{Darboux's Theorem}

\begin{itemize}
\tightlist
\item
  Theorem: If f differentiable on {[}a,b{]} and k between f'(a) and
  f'(b), then f'(c) = k for some c
\item
  Consequence: f' has IVP even if discontinuous
\item
  Consequence: f' cannot have jump discontinuities
\end{itemize}

\textbf{Lipschitz Functions}

\begin{itemize}
\tightlist
\item
  Definition: \textbar f(x) - f(y)\textbar{} ≤ K\textbar x - y\textbar{}
  for all x, y
\item
  Theorem: \textbar f'\textbar{} ≤ K on interval ⟹ f is Lipschitz with
  constant K
\item
  Corollary: Lipschitz ⟹ uniformly continuous
\item
  Connection: \textbar f'\textbar{} \textless{} 1 ⟹ contraction (links
  to Ch 4 and Newton)
\end{itemize}

\textbf{L'Hôpital's Rule}

\begin{itemize}
\tightlist
\item
  Theorem: f(a) = g(a) = 0, g' ≠ 0 near a, lim f'/g' = L ⟹ lim f/g = L
\item
  Proof via Cauchy MVT
\item
  Warning: must check lim f'/g' exists
\item
  Remark: ∞/∞ form and x → ∞ in exercises
\end{itemize}

\section{Power Series \& Taylors
Theorem}\label{power-series-taylors-theorem}

\textbf{Higher Derivatives}

\begin{itemize}
\tightlist
\item
  Definition: f'\,`, f'\,'\,', \ldots, f⁽ⁿ⁾
\item
  Notation: f⁽⁰⁾ = f
\end{itemize}

\textbf{Taylor Polynomials}

\begin{itemize}
\tightlist
\item
  Definition: Pₙ(x) = Σₖ₌₀ⁿ f⁽ᵏ⁾(a)/k! (x-a)ᵏ
\item
  Unique polynomial of degree ≤ n matching f, f', \ldots, f⁽ⁿ⁾ at a
\end{itemize}

\textbf{Taylor's Theorem}

\begin{itemize}
\tightlist
\item
  Generalized Rolle: f, f', \ldots, f⁽ⁿ⁾ all vanish at a, and f(b) = 0 ⟹
  f⁽ⁿ⁺¹⁾(c) = 0 for some c
\item
  Polynomial MVT: f and h share first n derivatives at a, and f(b) =
  h(b) ⟹ f⁽ⁿ⁺¹⁾(c) = h⁽ⁿ⁺¹⁾(c)
\item
  Theorem (Lagrange remainder): f(x) = Pₙ(x) + f⁽ⁿ⁺¹⁾(c)/(n+1)! (x-a)ⁿ⁺¹
\item
  Error bound: \textbar f(x) - Pₙ(x)\textbar{} ≤ M/(n+1)!
  \textbar x-a\textbar ⁿ⁺¹ where M bounds \textbar f⁽ⁿ⁺¹⁾\textbar{}
\end{itemize}

\textbf{Term-by-Term Differentiation}

\begin{itemize}
\tightlist
\item
  Lemma: Σaₙxⁿ and Σnaₙxⁿ⁻¹ have same radius of convergence
\item
  Theorem: f(x) = Σaₙxⁿ ⟹ f'(x) = Σnaₙxⁿ⁻¹ on (-R, R)
\item
  Proof via Tannery/dominated convergence
\item
  Corollary: Power series are infinitely differentiable
\item
  Corollary: aₙ = f⁽ⁿ⁾(0)/n! --- power series equal their Taylor series
\end{itemize}

\textbf{When Does the Taylor Series Converge to f?}

\begin{itemize}
\tightlist
\item
  Key question: Rₙ(x) → 0?
\item
  Power series: always yes (by construction)
\item
  General smooth functions: not necessarily!
\item
  Preview: smooth ≠ analytic (example requires exp, see 7.4)
\end{itemize}

\textbf{Warning: Takagi's Function}

\begin{itemize}
\tightlist
\item
  Definition: T(x) = Σ s(2ⁿx)/2ⁿ where s(x) = dist(x, nearest integer)
\item
  Theorem: T is continuous everywhere, differentiable nowhere
\item
  Proof sketch: uniform convergence gives continuity; careful difference
  quotient analysis gives nowhere differentiable
\item
  \textbf{The lesson}: Power series (limits of polynomials) are
  infinitely differentiable. But general limits of differentiable
  functions can be nowhere differentiable.
\item
  Remark: Full story of when limits preserve differentiability in

\end{itemize}

\section{Newton's Method}\label{newtons-method}

\textbf{The Algorithm}

\begin{itemize}
\tightlist
\item
  Problem: Find root of f(x) = 0
\item
  Newton iteration: xₙ₊₁ = xₙ - f(xₙ)/f'(xₙ)
\item
  Geometric interpretation: follow tangent line to x-axis
\end{itemize}

\textbf{Convergence via Contraction}

\begin{itemize}
\tightlist
\item
  Define g(x) = x - f(x)/f'(x); fixed point of g is root of f
\item
  Compute: g'(x) = f(x)f'\,`(x)/(f'(x))²
\item
  At simple root r: g'(r) = 0
\item
  Theorem: For x₀ near r, Newton converges
\item
  Proof: g'(r) = 0 ⟹ \textbar g'\textbar{} \textless{} 1 near r ⟹ g is
  contraction
\end{itemize}

\textbf{Quadratic Convergence via Taylor}

\begin{itemize}
\tightlist
\item
  Theorem: εₙ₊₁ ≈ {[}f'\,`(r)/(2f'(r)){]} εₙ²
\item
  Proof: Taylor expand f(xₙ) around r
\item
  Consequence: errors square --- digits roughly double each step
\end{itemize}

\textbf{Examples}

\begin{itemize}
\tightlist
\item
  √2: xₙ₊₁ = (xₙ + 2/xₙ)/2 --- the Babylonian method! (callback to Ch 2)
\item
  ∛5: xₙ₊₁ = (2xₙ + 5/xₙ²)/3
\end{itemize}

\textbf{Failure Modes}

\begin{itemize}
\tightlist
\item
  Multiple roots: g'(r) ≠ 0, only linear convergence
\item
  Bad starting points: may cycle, diverge, or find wrong root
\item
  f'(xₙ) = 0: division by zero
\end{itemize}

\textbf{Looking Ahead}

\begin{itemize}
\tightlist
\item
  Newton is fixed-point iteration: xₙ₊₁ = g(xₙ)
\item
  Picard iteration for ODEs: same idea in function space
\item
  Contraction mapping theorem (Ch 4) guarantees convergence in both
  settings
\end{itemize}

\chapter{Integration}\label{integration}

\section{Axioms}\label{axioms}

\begin{itemize}
\tightlist
\item
  What properties should ∫{[}a,b{]} f have?
\item
  \textbf{Axiom 1 (Rectangles)}: ∫{[}a,b{]} k = k(b−a) for constant k
\item
  \textbf{Axiom 2 (Monotonicity)}: f ≤ g on {[}a,b{]} ⟹ ∫{[}a,b{]} f ≤
  ∫{[}a,b{]} g
\item
  \textbf{Axiom 3 (Additivity)}: ∫{[}a,b{]} f = ∫{[}a,c{]} f +
  ∫{[}c,b{]} f for c ∈ (a,b)
\item
  These say nothing about \emph{which} functions are integrable --- only
  how the integral behaves
\end{itemize}

\textbf{Theorems from the Axioms}

\begin{itemize}
\tightlist
\item
  \textbf{Bounds theorem}: m ≤ f ≤ M ⟹ m(b−a) ≤ ∫f ≤ M(b−a)

  \begin{itemize}
  \tightlist
  \item
    Proof from monotonicity + rectangles
  \end{itemize}
\item
  \textbf{Continuity of F}: F(x) = ∫ₐˣ f is continuous

  \begin{itemize}
  \tightlist
  \item
    Proof from additivity + bounds
  \end{itemize}
\end{itemize}

\textbf{Upper and Lower Sums}

\begin{itemize}
\tightlist
\item
  Partition P = \{a = x₀ \textless{} x₁ \textless{} \ldots{} \textless{}
  xₙ = b\}
\item
  mᵢ = inf f on {[}xᵢ₋₁, xᵢ{]}, Mᵢ = sup f on {[}xᵢ₋₁, xᵢ{]}
\item
  Lower sum L(f,P) = Σ mᵢ(xᵢ − xᵢ₋₁)
\item
  Upper sum U(f,P) = Σ Mᵢ(xᵢ − xᵢ₋₁)
\end{itemize}

\textbf{The Trapping Theorem}

\begin{itemize}
\tightlist
\item
  \textbf{Theorem}: Any integral satisfying the axioms must satisfy
  L(f,P) ≤ ∫f ≤ U(f,P) for all P
\item
  Proof: Apply axioms to each subinterval, sum
\item
  \textbf{Corollary}: sup\_P L(f,P) ≤ ∫f ≤ inf\_P U(f,P)
\end{itemize}

\textbf{When is the Value Forced?}

\begin{itemize}
\tightlist
\item
  If sup\_P L(f,P) = inf\_P U(f,P), there is only one possible value for
  ∫f
\item
  The axioms completely determine the integral in this case
\item
  Key question: For which functions does sup L = inf U?
\end{itemize}

\textbf{Theorem: Continuous Functions Have Forced Values}

\begin{itemize}
\tightlist
\item
  \textbf{Theorem}: If f is continuous on {[}a,b{]}, then sup\_P L(f,P)
  = inf\_P U(f,P)
\item
  Proof:

  \begin{itemize}
  \tightlist
  \item
    f continuous on compact {[}a,b{]} ⟹ f uniformly continuous
  \item
    Given ε \textgreater{} 0, choose δ from uniform continuity
  \item
    Partition P with mesh \textless{} δ ⟹ Mᵢ − mᵢ \textless{} ε/(b−a) on
    each subinterval
  \item
    So U(f,P) − L(f,P) \textless{} ε
  \item
    Since ε arbitrary, sup L = inf U
  \end{itemize}
\item
  \textbf{Corollary}: If f is continuous and an integral satisfying the
  axioms exists, then the axioms force its value uniquely
\end{itemize}

\textbf{Examples: Values Forced by the Axioms}

\begin{itemize}
\tightlist
\item
  \textbf{Example}: For f(x) = x on {[}0,1{]}, the integral must equal
  1/2

  \begin{itemize}
  \tightlist
  \item
    Uniform partition Pₙ: L(f,Pₙ) = (n−1)/(2n), U(f,Pₙ) = (n+1)/(2n)
  \item
    Both → 1/2, so sup L = inf U = 1/2
  \end{itemize}
\item
  \textbf{Example}: For f(x) = x² on {[}0,1{]}, the integral must equal
  1/3

  \begin{itemize}
  \tightlist
  \item
    Calculation using Σi² = n(n+1)(2n+1)/6 shows sup L = inf U = 1/3
  \end{itemize}
\item
  These values are \emph{forced by the axioms} for any integral that
  exists
\end{itemize}

\textbf{The Question}

\begin{itemize}
\tightlist
\item
  We know \emph{what} the integral must be for continuous functions
\item
  But does an integral satisfying the axioms actually \emph{exist}?
\item
  We must verify that defining ∫f = sup L = inf U actually satisfies the
  axioms
\end{itemize}

\section{The Darboux Construction}\label{the-darboux-construction}

\subsection{The Definition}\label{the-definition}

\begin{itemize}
\tightlist
\item
  For continuous f on {[}a,b{]}, define: ∫ₐᵇ f = sup\_P L(f,P) = inf\_P
  U(f,P)
\item
  We must verify this definition satisfies our three axioms
\end{itemize}

\textbf{Partitions and Refinements}

\begin{itemize}
\tightlist
\item
  Partition P of {[}a,b{]}: finite set \{x₀, \ldots, xₙ\} with a = x₀
  \textless{} \ldots{} \textless{} xₙ = b
\item
  Refinement: Q refines P if P ⊂ Q
\item
  \textbf{Lemma}: Refinements improve bounds: P ⊂ Q ⟹ L(f,P) ≤ L(f,Q) ≤
  U(f,Q) ≤ U(f,P)
\item
  \textbf{Corollary}: Every lower sum ≤ every upper sum (use common
  refinement)
\end{itemize}

\textbf{Verification of Axiom 1 (Rectangles)}

\begin{itemize}
\tightlist
\item
  For constant k: mᵢ = Mᵢ = k for any partition
\item
  So L(k,P) = U(k,P) = k(b−a)
\item
  Therefore ∫k = k(b−a) ✓
\end{itemize}

\textbf{Verification of Axiom 2 (Monotonicity)}

\begin{itemize}
\tightlist
\item
  If f ≤ g on {[}a,b{]}, then on each subinterval: inf f ≤ inf g, sup f
  ≤ sup g
\item
  So L(f,P) ≤ L(g,P) and U(f,P) ≤ U(g,P) for all P
\item
  Taking sup over L and inf over U preserves inequality
\item
  Therefore f ≤ g ⟹ ∫f ≤ ∫g ✓
\end{itemize}

\textbf{Verification of Axiom 3 (Additivity)}

\begin{itemize}
\tightlist
\item
  For partitions P of {[}a,c{]} and Q of {[}c,b{]}, P ∪ Q is a partition
  of {[}a,b{]}
\item
  L(f, P∪Q) = L(f,P) + L(f,Q) and similarly for U
\item
  Taking sup/inf: ∫ₐᵇ f = ∫ₐᶜ f + ∫ᶜᵇ f ✓
\end{itemize}

\textbf{The Integral Exists}

\begin{itemize}
\tightlist
\item
  \textbf{Theorem}: For continuous f on {[}a,b{]}, the Darboux integral
  exists and satisfies all three axioms
\item
  The forced value is the actual value
\end{itemize}

\textbf{Payoff: Other Integrable Functions}

\textbf{(Probably mostly skip this!)}

\begin{itemize}
\tightlist
\item
  The definition ∫f = sup L = inf U makes sense whenever sup L = inf U
\item
  \textbf{Corollary}: Bounded functions with finitely many
  discontinuities are integrable

  \begin{itemize}
  \tightlist
  \item
    Near discontinuities: contribution to U − L bounded by 2M · (small
    width)
  \item
    Away from discontinuities: uniform continuity controls U − L
  \end{itemize}
\item
  \textbf{Exercise}: Monotone functions on {[}a,b{]} are integrable
\item
  We don't belabor integrability criteria here --- the Lebesgue integral

\end{itemize}

\textbf{L is a Logarithm}

\end{itemize}

\textbf{Arctangent}

\begin{itemize}
\tightlist
\item
  Definition: arctan(x) = ∫₀ˣ 1/(1+t²) dt
\item
  Key properties:

  \begin{itemize}
  \tightlist
  \item
    arctan'(x) = 1/(1+x²) --- rational function, no square roots!
  \item
    arctan(0) = 0
  \item
    arctan(x) → π/2 as x → ∞
  \item
    arctan(1) = π/4
  \end{itemize}
\end{itemize}

\textbf{π as Integral of Rational Function}

\begin{itemize}
\tightlist
\item
  Theorem: π/4 = ∫₀¹ 1/(1+t²) dt
\item
  Remarkable: π defined via circles equals integral of polynomials
\end{itemize}

\textbf{Taylor Series for Arctangent}

\begin{itemize}
\tightlist
\item
  Theorem: arctan(x) = x − x³/3 + x⁵/5 − ⋯ for \textbar x\textbar{}
  \textless{} 1
\item
  Proof: Integrate 1/(1+t²) = 1 − t² + t⁴ − ⋯ using Power Series III
\end{itemize}

\textbf{Gregory-Leibniz Series}

\begin{itemize}
\tightlist

\chapter{Extending the Integral}\label{extending-the-integral}

\section{Integrability}\label{integrability}

\textbf{Beyond Continuous Functions}

\begin{itemize}
\tightlist
\item
  Our axiomatic integral was built for continuous functions
\item
  But the construction works more broadly
\item
  Upper and lower sums make sense for any bounded function
\item
  \textbf{Definition}: \(f\) is \emph{Darboux integrable} if upper
  integral equals lower integral
\item
  What functions does this capture?
\end{itemize}

\textbf{The Class of Integrable Functions}

\textbf{Many functions are integrable}: - Continuous functions (by
construction) - Piecewise continuous functions (split at
discontinuities) - Monotone functions (upper/lower sums telescope) - The
ruler function (discontinuous on dense set, still integrable) - General
principle: discontinuities must be ``small''

\textbf{It's a vector space}: - If \(f, g\) integrable and
\(\alpha, \beta \in \mathbb{R}\), then \(\alpha f + \beta g\) integrable
- \(\int(\alpha f + \beta g) = \alpha \int f + \beta \int g\) -
Linearity inherited from the construction - We can do algebra with
integrable functions

\textbf{The Boundary}

\begin{itemize}
\tightlist
\item
  \(\chi_{\mathbb{Q}}\): discontinuous everywhere, not integrable
\item
  Upper integral \(= 1\), lower integral \(= 0\)
\item
  Not just pathological---it's the boundary of our class
\end{itemize}

\textbf{Power Series III Was Special}

\begin{itemize}
\tightlist
\item
  Callback to Chapter 9: term-by-term integration worked
\item
  \(\int \left( \sum a_n x^n \right) = \sum \frac{a_n x^{n+1}}{n+1}\)
\item
  Used for \(\ln(1+x)\), \(\arctan\), computing \(\pi\)
\item
  You might expect limits generally behave this well
\end{itemize}

\textbf{The Convergence Problem}

\begin{itemize}
\tightlist
\item
  \textbf{Failure Mode 1}: \(f_n = n \cdot \chi_{[0,1/n]} \to 0\) but
  \(\int f_n = 1\)

  \begin{itemize}
  \tightlist
  \item
    Limit integrable, integrals don't converge correctly
  \end{itemize}
\item
  \textbf{Failure Mode 2}:
  \(f_n = \chi_{\{q_1,\ldots,q_n\}} \nearrow \chi_{\mathbb{Q}}\)

  \begin{itemize}
  \tightlist
  \item
    Each \(f_n\) integrable with \(\int f_n = 0\)
  \item
    Limit not integrable
  \end{itemize}
\end{itemize}

\textbf{The class of Darboux integrable functions is not closed under
limits.}

\textbf{Why This Matters}

\begin{itemize}
\tightlist
\item
  Fourier series: need \(\int\) and \(\sum\) to interchange
\item
  Parameter integrals: need \(\int\) and \(\frac{d}{dt}\) to interchange
\item
  Power series were the exception; general limits fail
\end{itemize}

\textbf{The Key Observation}

\begin{itemize}
\tightlist
\item
  In Failure Mode 2: \(\int f_n = 0 \to 0\), obvious candidate is \(0\)
\item
  Problem isn't wrong answer---it's no answer when there's an obvious
  candidate
\item
  Could we extend by \emph{defining} \(\int \chi_{\mathbb{Q}} = 0\)?
\end{itemize}

\textbf{What We Want}

\begin{itemize}
\tightlist
\item
  \textbf{Preserve linearity}: we have a vector space, want to keep it
\item
  \textbf{Add MCT}: increasing limits with bounded integrals should work
\item
  The remarkable fact: demanding both forces a unique extension
\end{itemize}

\section{The Daniell Extension}\label{the-daniell-extension}

\textbf{The Plan}

\begin{itemize}
\tightlist
\item
  Two stages: first close under monotone limits, then close under
  subtraction
\item
  Must verify the extension still satisfies integral properties
\item
  Must verify MCT survives the second extension
\end{itemize}

\textbf{Dini's Theorem}

\begin{itemize}
\tightlist
\item
  Lemma: If \(f_n \in C[a,b]\) and \(f_n \searrow 0\) pointwise, then
  \(I(f_n) \to 0\)
\item
  Key technical tool bridging pointwise convergence to integral
  convergence
\item
  Proof uses compactness of \([a,b]\)
\end{itemize}

\textbf{Upper Functions}

\begin{itemize}
\tightlist
\item
  Definition: \(f \in L^\uparrow\) if \(f_n \in C[a,b]\) with
  \(f_n \nearrow f\) pointwise
\item
  Examples: continuous functions, \(\chi_{(a,b]}\)
\item
  Define \(I^+(f) = \lim I(f_n)\)
\end{itemize}

\textbf{Well-Definedness of \(I^+\)}

\begin{itemize}
\tightlist
\item
  Must show: different approximating sequences give same answer
\item
  Key Lemma: If \(f_n \nearrow f\) and \(g \in C[a,b]\) with
  \(g \leq f\), then \(I(g) \leq \lim I(f_n)\)
\item
  Proof uses Dini's theorem on the gap
  \(h_n = g - (f_n \wedge g) \searrow 0\)
\item
  Corollary: \(I^+\) well-defined
\end{itemize}

\textbf{Properties of \(I^+\)}

\begin{itemize}
\tightlist
\item
  Extension: agrees with \(I\) on \(C[a,b]\)
\item
  Monotonicity: \(f \leq g \Rightarrow I^+(f) \leq I^+(g)\)
\item
  Additive: \(I^+(f + g) = I^+(f) + I^+(g)\)
\item
  Positive homogeneity: \(c \geq 0 \Rightarrow I^+(cf) = c \, I^+(f)\)
\item
  MCT for \(L^\uparrow\): \(f_n \in L^\uparrow\), \(f_n \nearrow f\),
  \(\sup I^+(f_n) < \infty \Rightarrow f \in L^\uparrow\) and
  \(I^+(f_n) \to I^+(f)\)
\end{itemize}

\textbf{The Linearity Problem}

\begin{itemize}
\tightlist
\item
  \(L^\uparrow\) is a cone, not a vector space
\item
  Closed under addition and positive scalars
\item
  Not closed under subtraction: if \(f_n \nearrow f\), then
  \(-f_n \searrow -f\) (wrong direction)
\item
  We need subtraction for basic analysis
\end{itemize}

\textbf{Integrable Functions}

\begin{itemize}
\tightlist
\item
  Definition: \(f \in L^1\) if \(f = g - h\) for some
  \(g, h \in L^\uparrow\) with \(I^+(g), I^+(h) < \infty\)
\item
  Define \(I(f) = I^+(g) - I^+(h)\)
\item
  Must verify well-defined: if \(g_1 - h_1 = g_2 - h_2\), then
  \(I^+(g_1) - I^+(h_1) = I^+(g_2) - I^+(h_2)\)
\item
  Proof: \(g_1 + h_2 = g_2 + h_1\), both in \(L^\uparrow\), apply
  additivity
\end{itemize}

\textbf{Properties of \(I\) on \(L^1\)}

\begin{itemize}
\tightlist
\item
  \(L^1\) is a vector space
\item
  \(I\) is linear
\item
  Extension, monotonicity, interval additivity inherited
\end{itemize}

\textbf{MCT Survives}

\begin{itemize}
\tightlist
\item
  Key Lemma: If \(f \in L^1\) and \(f \geq 0\), then
  \(f \in L^\uparrow\)
\item
  Theorem (MCT for \(L^1\)): \(f_n \in L^1\), \(f_n \nearrow f\),
  \(\sup I(f_n) < \infty \Rightarrow f \in L^1\) and \(I(f_n) \to I(f)\)
\item
  Proof: WLOG \(f_n \geq 0\) (subtract \(f_1\)), apply key lemma, use
  MCT for \(L^\uparrow\)
\end{itemize}

\textbf{What We've Built}

\begin{itemize}
\tightlist
\item
  An integral on \(L^1 \supset C[a,b]\)
\item
  Satisfies original properties plus linearity plus MCT
\item
  Next: harvest the consequences
\end{itemize}

\section{Convergence Theorems}\label{convergence-theorems}

\textbf{Monotone Convergence Theorem}

\begin{itemize}
\tightlist
\item
  Theorem (MCT): \(f_n \in L^1\), \(f_n \nearrow f\),
  \(\sup I(f_n) < \infty \Rightarrow f \in L^1\) and \(I(f_n) \to I(f)\)
\item
  Already proved in 10.2; state cleanly here as the first payoff
\end{itemize}

\textbf{Dominated Convergence Theorem}

\begin{itemize}
\tightlist
\item
  Theorem (DCT): \(f_n \in L^1\), \(f_n \to f\) pointwise,
  \(|f_n| \leq g\) for some \(g \in L^1 \Rightarrow f \in L^1\) and
  \(I(f_n) \to I(f)\)
\item
  The workhorse theorem---this is what you actually use
\item
  Proof via MCT applied to \(\inf\)/\(\sup\) sequences
\end{itemize}

\textbf{Revisiting the Failures}

\begin{itemize}
\tightlist
\item
  Spike functions \(f_n = n \cdot \chi_{[0,1/n]}\): no dominating
  function (would need \(g(0) = \infty\))
\item
  DCT diagnoses exactly why interchange fails
\item
  Not a pathology---a precise answer
\end{itemize}

\textbf{Application: Differentiating Under the Integral}

\begin{itemize}
\tightlist
\item
  Setup: \(F(t) = \int_a^b f(x,t) \, dx\)
\item
  Theorem: If \(\frac{\partial f}{\partial t}\) exists and
  \(\left| \frac{\partial f}{\partial t} \right| \leq g \in L^1\), then
  \(F'(t) = \int_a^b \frac{\partial f}{\partial t} \, dx\)
\item
  Proof: Apply DCT to difference quotients
\end{itemize}

\subsection{Application: Integrating Series
Term-by-Term}\label{application-integrating-series-term-by-term}

\begin{itemize}
\tightlist
\item
  Setup: \(\sum f_n\) where each \(f_n \in L^1\)
\item
  Theorem: If \(\sum \int |f_n| < \infty\), then
  \(\int \sum f_n = \sum \int f_n\)
\item
  Proof: Partial sums dominated by \(\sum |f_n|\), apply DCT
\end{itemize}

\textbf{Completeness}

\begin{itemize}
\tightlist
\item
  Theorem: If \(f_n \in L^1\) and
  \(\sum \int |f_{n+1} - f_n| < \infty\), then \(f_n\) converges to some
  \(f \in L^1\)
\item
  Equivalently: Cauchy sequences in the \(\int |\cdot|\) sense converge
\item
  False for Darboux integrable functions
\item
  ``Completing the Integral''---we've filled the holes
\end{itemize}

\textbf{Series Closure}

\begin{itemize}
\tightlist
\item
  Theorem: If \(f_n \in L^1\) and \(\sum \int |f_n| < \infty\), then
  \(\sum f_n \in L^1\)
\item
  False for Darboux: \(f_n = \chi_{\{q_n\}}\), each integrable, sum is
  \(\chi_{\mathbb{Q}}\)
\item
  \(L^1\) closed under absolutely convergent series
\end{itemize}

\section{Measure Theory}\label{measure-theory}

\textbf{Null Sets}

\begin{itemize}
\tightlist
\item
  Definition: \(E\) is null if for every \(\varepsilon > 0\), \(E\)
  covered by countably many intervals of total length \(< \varepsilon\)
\item
  Equivalently: \(\chi_E \in L^1\) and \(I(\chi_E) = 0\)
\item
  Examples: finite sets, countable sets, Cantor set
\end{itemize}

\textbf{Properties of Null Sets}

\begin{itemize}
\tightlist
\item
  Subset of null is null
\item
  Countable union of null sets is null
\item
  Proof: cover \(n\)th set with intervals of total length
  \(\varepsilon / 2^n\)
\end{itemize}

\textbf{Almost Everywhere}

\begin{itemize}
\tightlist
\item
  Definition: Property holds a.e. if it fails only on a null set
\item
  ``\(f = g\) a.e.'' means \(\{x : f(x) \neq g(x)\}\) is null
\item
  ``\(f_n \to f\) a.e.'' means \(\{x : f_n(x) \not\to f(x)\}\) is null
\end{itemize}

\textbf{The A.E. Modification Theorem}

\begin{itemize}
\tightlist
\item
  Theorem: If \(f = g\) a.e. and \(f \in L^1\), then \(g \in L^1\) and
  \(I(f) = I(g)\)
\item
  Striking: modify on infinitely many points, integral unchanged
\item
  False for Darboux: \(f = 0\), \(g = \chi_{\mathbb{Q}}\), differ on
  null set, but \(\chi_{\mathbb{Q}}\) not Darboux integrable
\end{itemize}

\textbf{Measurable Sets}

\begin{itemize}
\tightlist
\item
  Definition: \(E\) is measurable if \(\chi_E \in L^1\)
\item
  Examples: intervals, open sets, closed sets, countable
  unions/intersections
\item
  Non-measurable sets exist (requires axiom of choice)
\end{itemize}

\textbf{Lebesgue Measure}

\begin{itemize}
\tightlist
\item
  Definition: \(\mu(E) = I(\chi_E)\) for measurable \(E\)
\item
  Properties: \(\mu(E) \geq 0\), \(\mu(\varnothing) = 0\),
  \(\mu([a,b]) = b - a\)
\item
  Countable additivity:
  \(\mu\left( \bigsqcup E_n \right) = \sum \mu(E_n)\)
\item
  Proof via DCT
\end{itemize}

\textbf{The Integral-First Philosophy}

\begin{itemize}
\tightlist
\item
  Traditional: measure → measurable functions → integral
\item
  Our approach: integral → measure as byproduct
\item
  For analysis, the integral is primary; measure serves it
\end{itemize}

\section{Why Lebesgue?}\label{why-lebesgue}

\textbf{Uniqueness}

\begin{itemize}
\tightlist
\item
  Theorem: Any extension of \(I\) from \(C[a,b]\) satisfying linearity
  and MCT must agree with ours
\item
  Proof sketch: MCT forces values on \(L^\uparrow\), linearity forces
  values on \(L^1\)
\item
  There was no choice---MCT determined everything
\end{itemize}

\textbf{Maximality}

\begin{itemize}
\tightlist
\item
  Theorem: \(L^1\) is the largest class where \(f\) integrable
  \(\Rightarrow |f|\) integrable
\item
  ``Absolute integrability'' property
\item
  Extensions beyond (like HK) lose this
\end{itemize}

\textbf{Connection to Derivatives}

\begin{itemize}
\tightlist
\item
  Theorem: \(f \in L^1\) iff \(f = F'\) a.e. for some absolutely
  continuous \(F\)
\item
  FTC for Lebesgue: cleaner than Darboux version
\item
  Preview of absolute continuity
\end{itemize}

\textbf{Completeness Revisited}

\begin{itemize}
\tightlist
\item
  \(L^1\) with \(d(f,g) = \int |f - g|\) is complete
\item
  In fact: \(L^1\) is the completion of \(C[a,b]\) under this metric
\item
  Every element of \(L^1\) is a limit of continuous functions
\item
  We added exactly the missing limits---nothing more
\end{itemize}

\textbf{A General Machine}

\begin{itemize}
\tightlist
\item
  The construction used the length axiom \(\mu([c,d]) = d - c\) only as
  input
\item
  Positivity, linearity, Daniell's condition did the work
\item
  Replace with \(\mu((c,d]) = g(d) - g(c)\) for increasing
  right-continuous \(g\)
\item
  Same machine produces a new integral
\item
  In Chapter N: this captures all finite Borel measures on
  \([a,b]\)---the Riesz representation theorem
\end{itemize}

\textbf{Beyond Lebesgue: The Henstock-Kurzweil Integral}

\begin{itemize}
\tightlist
\item
  Lebesgue isn't the only extension
\item
  HK: every derivative is integrable, full FTC
\item
  Example: \(F(x) = x^2 \sin(1/x^2)\), differentiable everywhere, \(F'\)
  not Lebesgue integrable
\item
  Tradeoff: HK has better FTC, but no \(L^p\) theory
\item
  Different integrals answer different questions
\end{itemize}

\textbf{Closing Perspective}

\begin{itemize}
\tightlist
\item
  Darboux: simplest integral for area under curves
\item
  Lebesgue: largest integral with good limit behavior
\item
  HK: largest integral with full FTC
\item
  For functional analysis: Lebesgue is essential
\end{itemize}
